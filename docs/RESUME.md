# 可写进简历的成果

**美妆电商用户运营分析｜Python + SQL（MySQL）、漏斗、Cohort 留存**

- 清洗并分析 1,958 万条美妆网店用户行为事件，围绕 164 万名观察用户建立严格 7 天漏斗、周留存、活跃构成和回流分群，产出 SQL、汇总结果及 10 图分析报告。
- 统一同用户同商品的时序与完整观察窗，测得浏览加购率 17.54%、加购后严格购买率 29.96%；统一 19 个合格批次后识别第 1→2 周留存由 8.85% 降至 5.55%。
- 对指定两周活跃下降 27.48% 进行算术拆解，识别首次观察用户减少贡献 58.64%，为该美妆网店形成选品决策提效、首访客群培育与沉默唤醒的运营试点方案。

面试边界：这是观察性历史数据项目，下降贡献不是原因识别，运营建议尚无上线增量收益。原始人数精确值及依据见 README 与 REPRODUCE；不要把 164 万称为新增客户，也不要声称亲自创造销售提升。
