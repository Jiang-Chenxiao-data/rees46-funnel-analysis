# REES46 事件字典

版本：2026-09-22。依据：本地清洗数据、质量审计及用户提供的 MySQL 代码。官方字段定义、来源页面和许可仍待核实；以下是本项目的分析解释。

## 数据范围与粒度

- 时间：2019-10-01 00:00:00 至 2020-02-29 23:59:59，统一按 UTC 解释。
- 原始 20,692,840 行；按原始全部 9 列去除 1,109,098 条完全重复副本后，保留 19,583,742 条事件。
- 一行表示一次保留的用户—商品行为事件；一行购买事件不等于一个独立订单。
- 数据不含可靠的注册时间、订单号、支付状态、渠道或设备字段。
- 本次归档的 12 项导入基准已从清洗后 Parquet 全量重新核对，见 [import_baseline.csv](../data/analysis_output/funnel_20260922/verification/import_baseline.csv)。

## 四类事件

| 原值 | 项目解释 | 清洗后事件数 | 在主漏斗中的处理 |
|---|---|---:|---|
| view | 浏览商品 | 9,656,790 | 每个用户—商品的首次浏览作为起点 |
| cart | 加入购物车 | 5,652,991 | 取起点之后第一次加购，时间必须严格晚于浏览 |
| remove_from_cart | 移出购物车 | 2,987,859 | 保留原事件；当前三步漏斗不使用，也不据此取消或重置已有加购 |
| purchase | 记录的购买行为 | 1,286,102 | 严格漏斗取合格加购之后第一次购买；分支另取浏览之后第一次购买 |

purchase 仅按记录的行为解释，不额外宣称已核实支付成功、订单完成或退款状态。

## 清洗后字段

| 字段 | MySQL 类型 | 解释及处理 |
|---|---|---|
| event_time | DATETIME NOT NULL | 秒级事件时间；以 UTC 解释，类型本身不存时区 |
| event_type | VARCHAR(20) NOT NULL | 上述四类事件 |
| product_id | BIGINT NOT NULL | 商品编号；严格路径必须匹配同一商品 |
| category_id | BIGINT NOT NULL | 类目编号；保持整数精度，不经浮点转存 |
| price | DECIMAL(12,2) NOT NULL | 记录的事件价格；零价、负价保留，不因价格异常删除行为 |
| user_id | BIGINT NOT NULL | 用户编号；最终漏斗人数按此字段去重 |
| user_session | CHAR(36) NULL | 原始会话标识；保留缺失值，不要求各步骤在同一会话 |

原始 brand、category_code 在正式清洗中已删除，不作为当前可直接使用的分群字段。去重发生在删除这两列之前，不能对清洗后 7 列再次去重来替代原规则。

## 分析限制

- 同秒不同事件没有可靠的先后顺序，严格路径只接受后一步时间大于前一步时间。
- 会话存在跨用户和超长跨度情况，主漏斗不强制同一会话。
- 零价、负价行为仍有效；收入或退款分析需另定规则。
- 周留存已采用全部四类有效事件作为活跃，UTC 周一至周日，用户周去重；首尾观察边界与验收证据见 2026-10-20 留存核对记录和交接文件第 24 节。
- 用户首次观察时间只能代表首次出现在数据中，不等于首次注册时间。
